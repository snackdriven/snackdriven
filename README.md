### kayla young (snackdriven) · senior qa engineer

**i find bugs for money and introduce them for fun.**

6+ years in QA (mostly healthcare software), based in Arkansas, working remote. i investigate software problems, define acceptance checks, and design AI-assisted QA workflows that make the work easier to verify.

i also practice DDD: *dopamine-driven development*. it explains the repo count. for my personal builds, i define the behavior and checks; AI writes the code, and i test whether it actually holds up.
